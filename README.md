# Axis & Allies — the war in review

A read-only look back at our 11-round custom Axis & Allies game: the Newsreel
(three rival newspapers), the replay on the globe and the war map, analytics
and honours, and the full event log.

**Open it here: https://ryancurtisslee.github.io/Axis-and-Allies-Game-14/**

(Served by GitHub Pages from this repository's `main` branch. Or download the
files and serve the folder from any web server; opening `index.html` straight
from disk won't load the map.)

Built from the game tracker's review build (`frontend/scripts/build-review.mjs`).
